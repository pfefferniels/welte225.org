This site collects the various projects that I have created as part of my dissertation Grünfelds Geist. All of them have Grünfeld's recording of Schumann's Träumerei for Welte-Mignon (1905) as their subject.

Projects

Roll Desk
Both editor and viewer for piano roll editions, including multiple collated copies, a stemma of versions of piano rolls and explicit editorial assumptions. viewer editor github repo
MPM Desk
Viewer and editor for interpreting a recorded performance as Music Performance Markup. viewer editor github repo
welte225.org
The roll's performance with the pianist's inner voice humming along and a harmonic reduction of the piece, at any degree of elaboration: from a sketch of the harmonies in half notes to the piece itself. On a page of its own, the performance as a piano roll over a grand staff, with what was said of the playing over the passages it is about. open Träumerei, described source
linked-rolls
TypeScript library for creating and modifying critical piano roll editions in the Roll Edition Format. github repo
welte-t100
Library for emulating piano rolls for the Welte T-100. github repo
espressivo
Library for creating, manipulating and rendering Music Performance Markup. In large parts a port of meico. github repo
MLign
Learned note-level alignment of a score (MEI or MusicXML) with a MIDI performance, inspired by TheGlueNote. github repo
As played by
MEI customization for embedding performance alignments within the MEI itself. A fork of Verovio renders such MEI with the score laid out along the time of the performance. open github repo verovio fork
condon-dates
When the red Welte rolls of the Condon collection at Stanford were punched, who signed them, the paper they were cut on and the perforators that cut them, and the premises these give for dating a roll. The edition of WM 225 cites these premises in dating copies of the roll. open premises github repo
Welte Ads
A TEI collection of advertisements for the Welte-Mignon. open github repo

Data

Roll edition
The edition of WM 225 as JSON-LD in the Roll Edition Format. edition.jsonld format
Editorial principles
The principles the edition follows, which its creation names, whether the editor applied them or a program did, with the classes and properties that state them. rules
Vocabulary
The Roll Edition Ontology, a lightweight extension of CIDOC CRM and LRMoo for editions of piano rolls, with its type vocabulary. ontology types
Performance
The roll's performance reconstructed as Music Performance Markup, with the transcription, the score and the work file it was fitted from. performance.mpm transcription.mei score.msm work.json format

Identifiers

The edition is https://welte225.org/, and its entities have IRIs below it:

/<id>
a version, copy, feature, edit, motivation or belief, opened in Roll Desk
/symbol_<id>
a symbol read from the roll, opened in Roll Desk
/rules#<id>
an editorial principle
/mpm/<id>
a call of the performance reconstruction, opened in MPM Desk

A UUID may be shortened to its first eight characters. Premises, classes of paper and hands come from condon-dates, under https://w3id.org/condon-welte/.
