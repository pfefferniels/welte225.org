This site collects the various projects that I have created as part of my dissertation Grünfelds Geist. All of them have Grünfeld's recording of Schumann's Träumerei for Welte-Mignon (1905) as their subject.

Projects

Roll Desk
Both editor and viewer for piano roll editions, including multiple collated copies, a stemma of versions of piano rolls and explicit editorial assumptions. viewer editor github repo
MPM Desk
Viewer and editor for interpreting a recorded performance as Music Performance Markup. viewer editor github repo
linked-rolls
TypeScript library for creating and modifying critical piano roll editions in the Roll Edition Format. github repo
welte-t100
Library for emulating piano rolls for the Welte T-100. github repo
espressivo
Library for creating, manipulating and rendering Music Performance Markup. In large parts a port of meico. github repo
As played by
MEI customization for embedding performance alignments within the MEI itself. A fork of Verovio renders such MEI with the score laid out along the time of the performance. open github repo verovio fork
Welte Ads
A TEI collection of advertisements for the Welte-Mignon. open github repo

Data

Roll edition
The edition of WM 225 as JSON-LD in the Roll Edition Format. edition.jsonld format
Vocabulary
The Roll Edition Ontology, a lightweight extension of CIDOC CRM and LRMoo for editions of piano rolls, with its type vocabulary. ontology types
Performance
The roll's performance reconstructed as Music Performance Markup, with the transcription, the score and the work file it was fitted from. performance.mpm transcription.mei score.msm work.json format

Identifiers

Every entity of the edition has an IRI under this domain. Each of them opens the edition at that entity in Roll Desk: the edition itself is https://welte225.org/, a copy is https://welte225.org/copy/<id>, a symbol read from the roll is https://welte225.org/symbol_<id>, and a hole on a copy is https://welte225.org/<id>. A segment of the performance reconstruction is https://welte225.org/mpm/<id> and opens at that segment in MPM Desk.
